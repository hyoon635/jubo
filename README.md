# 임마누엘교회 중등부 주보 만들기

매주 주보(A4 가로 2면), 설교·찬양대 썸네일, 카톡·유튜브 글을 만드는 페이지입니다.

- 페이지 주소: https://hyoon635.github.io/jubo/
- 데이터 저장: 비공개 저장소 `hyoon635/jubo-records` (페이지의 **기록** 탭에서 GitHub 열쇠를 한 번 넣으면 PC·휴대폰에서 이어서 작업)

## 매주 하는 일
1. **이번 주 내용** 탭에 전달받은 메시지를 붙여 넣고 **주보에 넣기**
2. 미리보기 확인 → **PDF 저장**, **썸네일 저장**
3. **카톡·유튜브** 탭에서 글 복사

PDF·이미지·썸네일을 저장하면 그 주 기록이 `jubo-records`에 자동으로 쌓입니다.
