# 구글 시트에 주보 저장하기 (처음 한 번만)

GitHub 열쇠 없이 **시트 저장 주소 + 비밀번호**만으로 PC와 휴대폰에서 주보를 이어서 쓰는 방법입니다.
주차별 기록은 시트의 `주보 기록` 탭에 한 줄씩 쌓여서 시트에서 바로 볼 수 있어요.

## 1. 시트 만들기
1. 구글 드라이브에서 새 구글 시트를 만듭니다. 이름 예: `중등부 주보 저장소`
   - 기도자 시트와 따로 두는 걸 권해요. 이 시트는 **공유하지 않아도** 됩니다.

## 2. 코드 붙여 넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs`에 있던 내용을 모두 지우고, 이 폴더의 [`Code.gs`](Code.gs) 내용을 통째로 붙여 넣습니다.
3. 맨 위 줄의 `'여기에-비밀번호'`를 선생님들끼리 쓸 비밀번호로 바꿉니다.
   ```js
   const PASSWORD = '우리만-아는-비밀번호';
   ```
4. 💾 저장을 누릅니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. 아래처럼 정하고 **배포**를 누릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 처음에는 권한 승인 창이 뜹니다. 본인 구글 계정을 고른 뒤:
   - **"Google hasn't verified this app"(Google에서 확인하지 않은 앱)** 화면이 나오면 왼쪽 아래 **Advanced(고급)** → 맨 아래 **Go to 프로젝트 이름 (unsafe)(…(으)로 이동(안전하지 않음))** 을 누릅니다.
   - 다음 화면에서 **Allow(허용)** 를 누릅니다.
   - 내가 직접 만든 스크립트라서 구글 심사를 받지 않았다는 안내일 뿐이에요. 개인이 만든 Apps Script는 모두 이 화면이 나옵니다. 권한은 이 시트 하나에만 해당돼요(`@OnlyCurrentDoc`).
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 주보 페이지에 넣기 (기기마다 한 번)
1. 주보 페이지 **기록** 탭 → **구글 시트 연결 설정**을 엽니다.
2. 시트 저장 주소에 웹 앱 URL, 비밀번호에 정한 비밀번호를 넣습니다.
3. **연결 확인**을 눌러 `"…" 시트에 연결됐어요.`가 나오면 끝입니다.
4. **지금 저장**을 한 번 누르면 시트에 `_작업내용`(숨김)과 `주보 기록` 탭이 생깁니다.

이후에는 PDF·이미지·썸네일을 저장할 때와 페이지를 닫을 때 자동으로 저장돼요.

## 알아 두기
- **비밀번호를 바꾸려면**: 코드의 `PASSWORD`를 고치고 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**. 주소는 그대로예요.
- **코드를 고친 뒤에도** 같은 방법(새 버전)으로 다시 배포해야 반영돼요.
- 웹 앱 주소와 비밀번호를 아는 사람은 저장할 수 있어요. 주소·비밀번호는 선생님들끼리만 나눠 주세요.
- 구글 시트를 연결하면 GitHub 대신 시트에 저장합니다. GitHub로 돌아가려면 **이 기기에서 연결 지우기**를 누르세요.
- 연결 없이도 **파일로 보관 → 파일로 내보내기 / 파일 가져오기**로 기기를 옮기거나 백업할 수 있어요.
